    		 required

    		 ...

    Layer

    __init__(id, mag, anis, Ms, thickness, cellSurface, demagTensor, temperature=..., damping=...)

    The basic structure is a magnetic layer. Its parameters are defined by the constructor and may be altered by the drivers during the simulation time. If you want STT, remember to set the reference vector for the polarisation of the layer. Use setReferenceLayer function to do that.

    Parameters:

    Name Type Description Default
    id str

    identifiable name for a layer -- e.g. "bottom" or "free".

    		 required
    mag CVector

    initial magnetisation. Must be normalised (norm of 1). Used for quicker convergence.

    		 required
    anis CVector

    anisotropy of the layer. A normalised vector

    		 required
    Ms float

    magnetisation saturation. Unit: Tesla [T].

    		 required
    thickness float

    thickness of the layer. Unit: meter [m].

    		 required
    cellSurface float

    surface of the layer, for volume calculation. Unit: meter^2 [m^2].

    		 required
    damping float

    often marked as alpha in the LLG equation. Damping of the layer. Default 0.011. Dimensionless

    		 ...

    createAFMLayer(id, anis, Ms, thickness, cellSurface, demagTensor, damping=0.011, afmExchangeDriver=..., mag1=..., mag2=...) staticmethod

    Create an antiferromagnetic (AFM) layer, modelled as two exchange-coupled sublattices (mag1, mag2) sharing Ms/anis/damping. Only the RK4 solver mode supports AFM layers (no stochastic/temperature drivers).

    Parameters:

    Name Type Description Default
    id str

    identifiable name for a layer -- e.g. "bottom" or "free".

    		 required
    anis CVector

    anisotropy of the layer, shared by both sublattices.

    		 required
    Ms float

    magnetisation saturation. Unit: Tesla [T].

    		 required
    thickness float

    thickness of the layer. Unit: meter [m].

    		 required
    cellSurface float

    surface of the layer, for volume calculation. Unit: meter^2 [m^2].

    		 required
    damping float

    Gilbert damping, shared by both sublattices. Default 0.011.

    		 0.011
    afmExchangeDriver ScalarDriver

    intra-layer Neel exchange coupling driver (J/m^2) between the two sublattices. Strongly negative favours antiparallel alignment.

    		 ...
    mag1 CVector

    initial magnetisation of sublattice A. Normalised. Defaults to the canonical Neel ground state (1, 0, 0).

    		 ...
    mag2 CVector

    initial magnetisation of sublattice B. Normalised. Defaults to the canonical Neel ground state (-1, 0, 0).

    		 ...
